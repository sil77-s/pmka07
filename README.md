Практика ПМ.07. Вариант 03
Предметная область: Медицинская клиника
СУБД: MySQL 8.0
ОС: Debian 12

Состав репозитория:
sql/ SQL-скрипты настройки прав и исходные данные.
scripts/ скрипт автоматизации (run.sh) и индивидуальное дополнение (verify_restore.sh).
out/ результаты работы скрипта (daily_stats.txt).
backup/ файлы контрольных замеров до и после восстановления.
logs/ журналы выполнения скриптов.
config_cron.txt параметры настроенного расписания.
